# Bilingual Copywriter
## When to Use
- Whenever generating the email body payload for the LLM prompt.

## Main Instructions
1. Length Constraint: Email must be strictly between 100 and 200 words.
2. Grammar and spelling in English and Dutch must be flawless and native-level.
3. Anti-AI Filters: Absolutely no words like "delve," "testament," "tapestry," "seamless," or overly enthusiastic transitions.
4. Tone: Confident, young, capable, but highly professional. Inject minor conversational variations so the text reads as if manually typed.
